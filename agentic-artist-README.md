# Agentic DJ

An agentic AI music agent with built in ideation, generation, self critique, and a memory loop.

## What it does

- **Ideation** — generates creative direction for new tracks  
- **Generation** — produces instrumental only music locally using Stable Audio Open  
- **Tagging** — organizes and labels generated output  
- **Self critique and memory loop** — planned for later phases, enabling the agent to evaluate its own output and improve over time

## Scope

- Focused on music generation rather than visual art  
- Instrumental only  
- Designed to sync generated tracks to Apple Music (via Sync Library) for on the go listening

## Architecture

- Local generation using Stable Audio Open  
- Currently in Phase 1: local optimization and generation

## Why it exists

This project is aimed to explore what an agentic DJ looks like when built and directed by someone outside a traditional engineering background.

## Status

Actively in development. Phase 1 underway generation of tracks and self critique  
Phase 2 will focus on the memory loop.
